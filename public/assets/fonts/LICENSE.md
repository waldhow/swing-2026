# Typsnitt

Självhostade kopior av Google Fonts-filerna (latin + latin-ext), hämtade 2026-09-26.
Alla tre familjerna är licensierade under **SIL Open Font License 1.1** (https://openfontlicense.org).

| Familj | Upphov |
| --- | --- |
| Hanken Grotesk | Hanken Design Co. — https://github.com/marcologous/hanken-grotesk |
| Newsreader | Production Type — https://github.com/productiontype/Newsreader |
| IBM Plex Mono | IBM Corp. — https://github.com/IBM/plex |

Byt vikter eller familjer genom att hämta ny CSS från fonts.googleapis.com
(med en modern User-Agent för woff2), ladda ner filerna och peka om `src` i `fonts.css`.
